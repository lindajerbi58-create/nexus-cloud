# NEXUS Cloud

Distributed, fault-tolerant and self-healing cloud storage platform.

## Overview

NEXUS Cloud is a distributed storage system designed
to store, replicate and recover files across multiple
storage nodes.

## Planned Features

- Distributed file storage
- File splitting and reconstruction
- Automatic block replication
- Java RMI metadata management
- TCP socket communication
- Heartbeat and failure detection
- Automatic self-healing
- SHA-256 data integrity verification
- Real-time infrastructure monitoring
- Authentication and access control

## Technology Stack

- Java 17
- Java RMI
- TCP Sockets
- Apache Maven
- Spring Boot
- Next.js
- TypeScript
- PostgreSQL
- Docker
